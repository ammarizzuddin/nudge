# Changelog

All notable changes to Nudge will be documented in this file.

## 0.1.0 — Beta

- Added local EventKit calendar monitoring with calendar filtering.
- Added configurable reminder and post-start grace periods.
- Added the animated, draggable desktop companion.
- Added snooze, dismiss and escalating reminder sounds.
- Added Zoom, Microsoft Teams and Google Meet detection.
- Added meeting join and physical-location actions.
- Added an optional live menu-bar countdown.
- Added next-event and following-event details in the menu.
- Added launch-at-login and animation preferences.
- Added first-run onboarding and Calendar permission recovery.
- Added automated coverage for reminder timing, event ordering and meeting links.
